# billing-snapshot

Read CLAUDE.md. Run billing-preview first. Confirm quantity, allowance, time approval and selected period with the operator. Save one frozen billing proposal for that client and month. This records a proposal, never issues an invoice or moves money. Late entries require reviewed adjustments outside the existing snapshot.

Run `npm run msp -- billing-snapshot YYYY-MM <client> --json`. For an overview in aligned text, omit --json. Replace angle-bracket arguments with actual values, never literal placeholders.

Start with current records. State unknowns. Never send, publish or transfer money.
