# draft-billing

Read CLAUDE.md. Read saved billing proposals and write a billing discussion in drafts. Keep amounts and currencies together. Do not issue an invoice or send.

Run `npm run msp -- draft-billing <client> --json`. For an overview in aligned text, omit --json. Replace angle-bracket arguments with actual values, never literal placeholders.

Start with current records. State unknowns. Never send, publish or transfer money.
