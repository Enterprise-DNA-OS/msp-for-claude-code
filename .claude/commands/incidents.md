# incidents

Read CLAUDE.md. Read the incident summary and assessment before interpreting a finding. Do not put breached files or credentials in the record.

Run `npm run msp -- incidents --json`. For an overview in aligned text, omit --json. Replace angle-bracket arguments with actual values, never literal placeholders.

Start with current records. State unknowns. Never send, publish or transfer money.
