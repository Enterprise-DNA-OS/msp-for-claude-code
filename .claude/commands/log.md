# log

Read CLAUDE.md. Record actual work with ticket, technician, description, timestamp and whole minutes. Billable does not mean approved. Use approved=true only when the operator states it was approved.

Run `npm run msp -- log <json-time-entry> --json`. For an overview in aligned text, omit --json. Replace angle-bracket arguments with actual values, never literal placeholders.

Start with current records. State unknowns. Never send, publish or transfer money.
