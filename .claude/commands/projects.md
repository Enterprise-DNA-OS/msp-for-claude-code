# projects

Read CLAUDE.md. Compare recorded project minutes against the budget and due date. Negative remaining time means over budget. This is time consumption, not monetary profit.

Run `npm run msp -- projects --json`. For an overview in aligned text, omit --json. Replace angle-bracket arguments with actual values, never literal placeholders.

Start with current records. State unknowns. Never send, publish or transfer money.
