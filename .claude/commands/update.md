# update

Read CLAUDE.md. Read the record first and update only supplied fields. Closed tickets need an actual closed_at timestamp. Billed time and ticket ownership with time are protected. No deleting.

Run `npm run msp -- update <entity> <name-or-id> <json> --json`. For an overview in aligned text, omit --json. Replace angle-bracket arguments with actual values, never literal placeholders.

Start with current records. State unknowns. Never send, publish or transfer money.
